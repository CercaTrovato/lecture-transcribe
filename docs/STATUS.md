# 本地发布副本验收状态

日期：2026-10-07。此目录为独立发布副本；原 `lecture-transcribe` 及其历史资料保留。

## 已实现并验证

- 四个模型均由用户主动下载、引用或卸载，启动与推理不会触发权重下载。
- 模型卡显示作用、体积、缺失影响、使用状态、下载进度与操作。
- 下载取消、同版本续传、重试、SHA-256/Git blob 校验；失败文件不成为已安装模型。
- 在任务使用期间拒绝卸载；外部模型只移除引用，原文件不删除。
- 可选择模型存储位置；切换目录不迁移或删除原目录文件。
- 不安装模型时仍可录音保存、导入音频、播放和查看已有历史。
- Turbo 实时和完整转录复用一个加载实例；标准双语使用 Turbo + 1.8B。大模型是选装增强功能。
- 实时双语稿与完整原文稿独立保存及切换，不把旧译文混配为最终精译。移除翻译模型后，历史译文仍可查看和下载。
- 同一前端、同一 Python 业务代码；Windows 当前路径不再固定到个人盘符或课程库。
- Windows Electron 应用首启实际下载运行组件，包内便携 Python 启动后台；未安装模型的主界面及四个模型卡渲染正常。

## 证据

- 20 项 Python 行为测试通过，包含完整下载生命周期、使用锁、无模型操作、外部引用与存储目录保护。
- 2 项 Node 桌面组件测试通过，包含完整性验证、显式安装与错误数据拒绝。
- Playwright：真实共享页面验证保存录音、下载/取消/续传/卸载流程、外部模型引用、使用中保护，以及历史译文保留。下载生命周期使用小型本地校验文件，不把它当作真实 7B 推理验证。
- 真实模型：使用已有 Turbo 与 1.8B，通过模拟麦克风输入自写测试文字，完成实时双语及结束后完整原文转录。没有重新下载大权重，没有采集现场麦克风声音。
- 打包应用：通过隐藏的 Electron 窗口和 CDP 验证从初次配置进入本机服务；使用下载组件里的 Python 3.12.13，而非开发环境解释器。
- 官方模型元数据请求已核对四个仓库文件清单、固定提交版本及哈希信息；没有因此下载权重。
